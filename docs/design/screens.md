# Screen specifications and exact copy

The global banner appears on every screen: **“Synthetic demo data · Calibrated to public aggregates · Results are illustrative, not validated.”** It remains visible in screenshots, exports, and mobile layouts. Never show an accuracy claim.

Every screen uses a page title, one primary action, a status region with `aria-live=polite` for nonurgent changes, and a reserved space for loading states. Error copy names the failed task and offers a retry. Offline copy states what remains available. Partial-data copy names the missing layer.

## Confirmation and undo copy

- Before saving extracted data: “Review every field against the photo. Save these values to this synthetic facility?” Buttons: “Go back” and “Confirm and save.”
- Before a redistribution proposal: “Prepare a transfer proposal for {quantity} {unit} of {commodity} from {source} to {recipient}?” Buttons: “Cancel” and “Prepare proposal.”
- After a reversible proposal: “Transfer proposal prepared.” Action: “Undo proposal.” If the backend has progressed the proposal beyond a reversible state, omit Undo and show “Contact your coordinator to change this proposal.”
- For canceling a run: “Cancel this run? Results already saved will remain available.” Buttons: “Keep running” and “Cancel run.”
