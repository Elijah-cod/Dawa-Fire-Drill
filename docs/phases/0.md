# Phase 0 demo notes: project rules

- Read `AGENTS.md` for product, data, model, security, workflow, and quality constraints.
- Read `README.md` for the synthetic-data and illustrative-output notice.
- Check `docs/design/APPROVAL.md` before starting frontend work.
- Inspect the split environment templates in `apps/api/.env.example` and `apps/web/.env.example`; never commit populated secrets.

Phase 0 remains in progress. See `docs/PROGRESS.md` for verification status and blockers.

Local settings demo: from `apps/api`, run `uv sync --extra dev` and `uv run pytest -q`. The required `DATABASE_URL` setting fails fast when absent; it is never read from the example template automatically.

Local service demo: `docker compose -f infra/compose.yaml up -d --build`, then `curl --fail http://localhost:8000/health`. The response states the synthetic-data policy. Stop with `docker compose -f infra/compose.yaml down`.
